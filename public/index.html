HTTP API

SMTP submission
SMTP_HOST=couriermesh
SMTP_PORT=2525
SMTP_USER=<KEY_ID>
SMTP_PASSWORD=<SECRET_FROM_CREATED_KEY>
SMTP_SECURE=false
SMTP_REQUIRE_TLS=true
When self-signed SMTP TLS is used, explicitly trust the generated certificate in the client. SMTP messages MUST include an X-CourierMesh-OTP header with the verification code. Standard free-form SMTP messages and attachments are rejected. Use HTTP API whenever possible.
Never publish SMTP port 2525 to the public internet. Keep API secrets on the server side.

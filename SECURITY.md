# Security policy

Please report potential security vulnerabilities privately through GitHub's **Report a vulnerability** feature (Security → Advisories → Report a vulnerability), if enabled for the published repository. Do not include live credentials or personal data in public issues. Until a security contact is established for your fork, use a private maintainer contact channel.

Supported release: latest tagged `1.x` only. We make no security certification claims. See [Security design](docs/SECURITY.md) before production use.
